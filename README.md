## 🛠️ Installation & Setup

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/Harsh6465/Portfolio.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the app:**
    ```bash
    npm start
    ```
